# Lola's Cafe — order & track demo

A working demo built to pitch the real thing: menu, cart, checkout, online payment
and live order tracking for Lola's Cafe, Ekrejeta, Abraka, Delta State.

Everything here is demo-grade on purpose: prices are samples, payment is a
simulated card screen, and orders live in the browser (no server yet).

The real build adds: their actual menu and photos, a real Paystack account,
orders landing in the kitchen with a queue, and the customer's WhatsApp number
receiving status updates. Installable to a phone home screen (PWA).

Built by John Enechukwu.
